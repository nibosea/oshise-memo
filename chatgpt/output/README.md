# ChatGPT 出力の置き場

ChatGPT（GPT-5.6 Sol）が返した出力を、ここに Markdown ファイルとして保存してください。
お姉さん（Claude Code）がここを見てレビューします。

## 保存ファイル名の目安
- `screen2-detail.md` … 画面2「お店詳細画面」の出力
- `screen3-edit.md` … 画面3「お店登録／編集画面」の出力
- 1ファイルにまとめて返ってきた場合は `wireframes-2-3.md` などでOK（お姉さんが分割・整理します）

## 保存のしかた（どちらでも）
- ChatGPT の出力をコピーして、このフォルダに `.md` ファイルとして貼り付け保存
- または「出力できたよ」とお姉さんに伝えてもらえれば、こちらで受け取って保存します
