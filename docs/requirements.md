# お店メモ（仮）— 要件定義書

> ステータス: **確定**（この文書が要件の一次ソース）
> 最終更新: 2026-07-14

## これは何
飲食店ごとに自分専用のメモを残せるアプリ。「このお店、前どんなカスタマイズにしたっけ？」という悩みを解消する。既存のグルメアプリが「他人向けの評価・口コミ」に強いのに対し、本アプリは「自分だけの再訪メモ」に特化する。

## 対象プラットフォーム
- まずは iPhone 向けに作る
- 将来的に Android にも展開する前提（ロジックは共通で使い回したい）
- 今回のスコープは iOS 版の MVP

## MVP の範囲
**やること**
- お店を手動で登録する
- お店ごとにメモを1つ持つ（自由記述・編集で上書き可能）
- 登録したお店・メモを一覧／検索で見返す
- お店・メモの編集・削除

**やらないこと（次フェーズ）**
- 位置情報による滞在検知、滞在時間による自動通知、地図上での自動同定
- 写真の保存
- お店のジャンル・評価（★）
- クラウド同期・アカウント機能

## データ構造
お店1件が、メモ1件を持つ（1対1）。
- **お店（Shop）**: 店ID / 店名 / メモ本文（自由記述・上書き可能）/ 登録日時 / 更新日時
- カスタマイズ内容・量の感想・総合の感想などは項目分けせず、すべて「メモ本文」の自由記述に集約する

## 画面構成（3画面）
1. **お店一覧画面（トップ）**: ナビゲーションバーにタイトルと右上「＋」ボタン、検索フィールド（店名・メモ本文を部分一致で絞り込み）、お店リスト（更新日時の新しい順、各行に 店名／メモ本文の先頭1〜2行／更新日）、空状態の表示
2. **お店詳細画面**: そのお店の店名とメモを表示。編集画面への入口
3. **お店登録／編集画面**: 店名・メモ本文を入力。既存店の場合はここで上書き編集・削除も行う

## 画面遷移
- お店一覧 →「＋」→ お店登録 → 保存で一覧に戻る
- お店一覧 → お店をタップ → お店詳細
- お店詳細 →「編集」→ お店編集（上書き・削除）→ 保存で詳細に戻る

## 技術前提
- 技術構成: **PWA（ホーム画面に置けるWebアプリ）で確定**。Xcode を使わず開発するため
- 対象OS: iOS（iPhone）優先、将来 Android 展開（PWAなので同一コードで両対応）
- データは端末内に保存（IndexedDB。クラウド同期・アカウントなし）
- 地図・位置情報・通知・カメラの権限は MVP では要求しない
- データ保存はリポジトリ層で抽象化する（後日クラウド同期に差し替えやすくするため）

## 収益化方針
- MVP は **完全無料**。広告は入れない
- 将来: **買い切りアンロック（Web決済／Stripe想定）** を検討。有料の目玉候補はクラウド同期・バックアップ・写真保存など（＝MVPで外した機能）

## 確定した仕様判断（2026-07-14）
- **技術構成**: PWA で確定（Xcode不要）
- **アプリ名**: UI表記は **「お店メモ」で統一**（プロダクト仮称の「ご飯メモ」は保留）
- **一覧画面の削除動線**: **左スワイプ削除 ＋ 編集画面内の削除ボタン**の両方を用意
- **詳細画面の日時表示**: **更新日時のみ**表示（登録日時は出さない）
- **未保存時の離脱**: 入力変更があるまま戻る操作をしたら **「変更を破棄しますか？」確認**を出す
